# Agentic CI/CD Pipeline & Metrics Tracking

This project implements an automated CI/CD pipeline using Google Cloud Build, Cloud Run, and BigQuery for tracking build metrics and logs.

## Project Structure
- `app/`: Application source code and routes.
- `tests/`: Pytest test suite (`test_main.py`, etc.).
- `cloudbuild.yaml`: Google Cloud Build configuration file defining the build, test, container push, and deployment steps.
- `fault_injection.py`: Script to inject test failures and test resilience/metrics logging.
- `requirements.txt`: Python package dependencies.
